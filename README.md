# 小小做到 · Little Wins

> 每一个做到，都值得被看见。

小小做到是一款低压力的每日成就记录应用。它不要求你建立连续打卡、
完成宏大目标或维持完美状态，只帮助你看见已经发生的努力。

对注意力困难、容易因“没有完成”而陷入挫败的人来说，起床、喝水、
回复一封拖延的邮件、带着焦虑参加会议，都可以是一件值得保存的小胜利。

## 产品原则

- **只负责写下来**：用户输入一句话，系统自动整理分类、颜色和反馈。
- **不惩罚中断**：没有断签、归零、落后提醒或“今天还没完成”的压力。
- **承认行为，不评价人格**：反馈温和、具体，不说教，也不过度夸张。
- **同一份记录，多种回看方式**：今日时间线、周月收藏板和年度回顾共享同一数据源。
- **数据属于用户**：支持自托管、JSON 导出，不接入第三方行为分析。

## 已实现的体验

- 一句话记录小胜利
- 未登录先记录，注册后将本机记录幂等迁移到账户
- 邮箱注册与登录，并保留 Google / 私有本机账户模式
- 六类本地自动分类，并支持用户修正
- 温情反馈与可选感受记录
- 今日时间线
- 本周、本月、半年收藏板
- 年度微光地图与非竞争性回顾
- 详情、编辑、珍藏与归档
- 存档恢复和完整 JSON 数据导出
- 桌面及移动端响应式界面

## 本地运行

需要 Node.js 20+、pnpm 与 Python 3。

```bash
pnpm install
pnpm dev
```

另开终端启动 API：

```bash
pnpm api
```

默认前端地址为 `http://localhost:5173`，API 地址为
`http://localhost:5000`。现有 Nightlio 数据库文件可以继续使用，项目会
保持读取兼容，避免迁移期间丢失记录。

邮箱注册登录默认开启，可通过 `ENABLE_EMAIL_AUTH=0` 关闭。用户在注册前写下
的首条小胜利只保存在当前设备；注册或登录成功后，前端会逐条、可重试地迁移，
只有服务端确认保存成功的记录才会从本机移除。

本地开发也会启用免密本机账户。公开部署必须启用邮箱或 Google 登录，或者设置
至少 12 位的 `LOCAL_ACCESS_PASSWORD`；生产环境会拒绝默认 JWT 密钥、免密登录
以及指向 localhost 的 CORS 配置。完整变量见 [`.env.example`](./.env.example)。

## 当前架构

- React 19 + Vite
- Flask API
- SQLite
- 本地规则分类，不需要外部 AI 服务
- Docker / Nginx 自托管基础

## 项目状态

当前为产品重构期的 `0.2.x` 版本。分类修正、感受、珍藏和归档已进入正式
数据库字段；旧版浏览器元数据会按账户迁移到服务端，注册前记录也可在登录后
安全迁移。邮箱验证、找回密码、系统通知、附件、搜索、完整的无障碍焦点管理
和自动化前端端到端测试仍在后续计划中。
